# Project instructions

- Gunakan React, TypeScript, Vite, React Router, Motion, native CSS, dan CSS Modules.
- Pertahankan satu application dengan route dari `src/app/themeRegistry.ts`.
- Instruksi dan sample message menggunakan Bahasa Indonesia; nama tema tetap Inggris.
- Jangan menambahkan backend, authentication, database, CMS, payment, atau upload.
- Jangan membuat abstraction sebelum ada kebutuhan nyata dari tema pertama.
- Gunakan semantic HTML, visible focus, keyboard support, dan reduced-motion.
- Jangan memakai external asset, copyrighted asset, Tailwind, atau generic component library.
- Sebelum handoff jalankan `npm run lint`, `npm run typecheck`, `npm run test:unit`, `npm run build`, dan Chromium smoke test.
